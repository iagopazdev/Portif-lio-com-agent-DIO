# Portfólio de Transição de Carreira - Iago Paz
Obs: Esse Readm foi criado com IA, mas revisado por mim o criador.

Este projeto é um portfólio pessoal desenvolvido com HTML, CSS e JavaScript para apresentar a jornada profissional, com foco em transição de carreira para a área de tecnologia, analise e desenvolvimento de sistemas, infraestrutura, suporte técnico e Inteligência Artificial.

O site foi construído com uma identidade visual moderna, com elementos de design responsivo, grade de câmera visual, seção de destaque do perfil, linha do tempo, cards de habilidades e links para redes sociais profissionais.

## Objetivo do projeto

O portfólio tem como objetivo:

- Apresentar a trajetória profissional e a transição de carreira do autor;
- Evidenciar competências ligadas a tecnologia, infraestrutura, dados, automação e IA;
- Reforçar uma imagem profissional com foco em comunicação técnica e personal branding;
- Demonstrar conhecimento prático em desenvolvimento front-end com HTML, CSS e JavaScript.

## Perfil profissional

Iago é natural de Manaus-AM e iniciou sua carreira na área de telecomunicações em 2013. Sua trajetória passou por emissoras de televisão e chegou à RedeTV!, onde atuou com operação técnica em transmissões ao vivo.

Com base nessa experiência, o projeto comunica a transformação da carreira do autor: da área audiovisual para a área de tecnologia, com foco em:

- Desenvolvimento web;
- Linux e infraestrutura;
- Automação com Python;
- IA Generativas.

## Página principal

O arquivo principal do projeto é [index.html](index.html), onde está o conteúdo semântico da página. Nele são organizados:

- Cabeçalho com nome e subtítulo profissional;
- Bloco de informações de localização;
- Botão de gravação REC;
- Seção “Sobre Mim” com narrativa pessoal e profissional;
- Seção “Minha Jornada” com timeline da carreira;
- Seção “Minhas Habilidades” com cards de competências;
- Rodapé com links para GitHub e LinkedIn.

## Estilos e visual

O visual foi estruturado em [style.css](style.css) com CSS moderno, incluindo:

- Importação de fonte externa com Google Fonts;
- Sistema de variáveis CSS para paleta de cores;
- Layout responsivo com suporte para telas menores;
- Estilização de títulos, cards, layout e navegação;
- Visual de recorte técnico com botão REC, timer e viewfinder;
- Hover effects, animações e estruturas visuais com foco em um visual premium.

## Interação com JavaScript

O comportamento interativo foi implementado em [script.js](script.js). A lógica que foi aplicada inclui:

- Acessos aos elementos DOM com `getElementById`;
- Controle de estado do botão de gravação;
- Timer de cronômetro em formato HH:MM:SS;
- Alternância de classes CSS para ativar visual de gravação;
- Exibição e ocultação do overlay de câmera `viewfinder`;
- Mensagens no console para acompanhar a interação do usuário.

## Exercícios e práticas práticas implementadas

Abaixo está uma visão dos exercícios e entregas que esta página demonstra na prática:

### 1. Estruturação semântica em HTML

Foi utilizado HTML5 com boas práticas de organização, incluindo:

- Uso da estrutura básica do documento;
- Uso de elementos semânticos como `header`, `main`, `section`, `footer`;
- Textos e conteúdo organizados com estrutura coerente para SEO e acessibilidade.

### 2. Layout responsivo com CSS

O CSS define a identidade visual da página e organiza elementos por regras de posicionamento e responsividade:

- `display: flex` para header e layout; 
- `grid-template-columns` para a grade de habilidades;
- Uso de media queries para adaptar a página em telas menores;
- Definição de cores, fontes, bordas, espaçamentos e background.

### 3. Interação com JavaScript

A página recebe interatividade por meio do JavaScript, explorando eventos do usuário:

- Clique no botão REC;
- Troca de texto do botão;
- Ação de iniciar e parar o timer;
- Aplicação de classes de visual ativo e inativo;
- Exibição de um overlay visual como uma grade de câmara.

### 4. Construção de interface visual inspirada em tecnologia

A interface foi pensada para comunicar uma identidade tecnológica e profissional:

- Cores com temas de cyber e visual premium;
- Indicadores de gravação e elementos de luz; 
- Gradientes e bordas com foco em diferenciação; 
- Apresentação da jornada em um formato que facilita leitura e navegação.

## Como abrir o projeto localmente

Para visualizar o portfólio no navegador, basta abrir o arquivo [index.html](index.html) diretamente em um navegador ou servir o projeto localmente com um servidor HTTP simples.

Opção 1 — abrir diretamente:

```bash
index.html
```

Opção 2 — servidor local com Python:

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```
